Cálculo del área de un cilindro circular recto, sin tapas y con tapas

La superficie curva de un cilindro se puede abrir y estirar sobre una mesa sin romperla ni arrugarla. Al hacerlo queda un rectángulo, y el área de un rectángulo ya se sabe calcular.

Disfruta la animación

A la izquierda queda el cilindro circular recto de radio \(r\) y altura \(h\), siempre de pie. A la derecha, una copia del mismo cilindro se desarma: primero se destapa hacia arriba, después se destapa hacia abajo, y por último su superficie lateral se corta por el frente y se abre desde el centro hacia los dos lados, hasta quedar plana como una lonja.

  • Centro \(O\): el centro de cada base circular.
  • Radio \(r\): el radio de cada una de las dos bases circulares del cilindro, medido desde su centro \(O\).
  • Altura \(h\): la distancia entre las dos bases. En un cilindro recto es también el largo del costado.
  • Tapas verdes: las dos bases. Al destaparse se ven de frente: cada una es un círculo de radio \(r\) y área \(\pi r^2\).
  • Lonja azul: la superficie lateral, que se abre desde el centro hacia sus dos lados. Al quedar plana es un rectángulo de alto \(h\).
  • Borde naranja: el borde que rodeaba la tapa. En el cilindro es una circunferencia de largo \(2\pi r\); al abrirse la lonja queda estirado en línea recta y es el ancho del rectángulo.

Sin tapas: el área lateral

  1. Se corta la superficie lateral a lo largo de una recta vertical y se abre sobre el plano, como una lonja. Como el cilindro es recto, el corte es perpendicular a las bases y la figura que queda es un rectángulo.
  2. El alto del rectángulo es el largo del corte, que es la altura del cilindro: \[\text{alto}=h\]
  3. El ancho del rectángulo es el borde de la base, que antes rodeaba el círculo completo. Ese largo es el perímetro de una circunferencia de radio \(r\): \[\text{ancho}=2\pi r\]
  4. Al estirar la superficie no se agrega ni se quita material, así que el área no cambia. El área lateral es el área del rectángulo, ancho por alto: \[A_{\text{sin tapas}}=2\pi r\cdot h\]

Con tapas: el área total

  1. Cada tapa es un círculo de radio \(r\). El área de un círculo es: \[A_{\text{tapa}}=\pi r^2\]
  2. El cilindro cerrado tiene dos tapas iguales: \[2\cdot A_{\text{tapa}}=2\pi r^2\]
  3. El área total es el área lateral más el área de las dos tapas: \[A_{\text{con tapas}}=2\pi r h+2\pi r^2\]
  4. Los dos sumandos tienen el factor \(2\pi r\). Se saca como factor común: \[A_{\text{con tapas}}=2\pi r\,(h+r)\]

Área de un cilindro circular recto

\[A_{\text{sin tapas}}=2\pi r h\qquad\qquad A_{\text{con tapas}}=2\pi r\,(h+r)\]

Con una sola tapa, como un vaso o un tarro abierto, se suma un solo círculo: \(A=2\pi r h+\pi r^2\).

Ejercicios de cálculo

ACalcula el área de un cilindro circular recto sin tapas, de radio \(3\ \text{cm}\) y altura \(10\ \text{cm}\).

Pista

Sin tapas solo se cuenta el rectángulo: \(A=2\pi r h\).

Solución paso a paso
  1. Datos: \[r=3\ \text{cm}\qquad h=10\ \text{cm}\]
  2. Fórmula sin tapas: \[A=2\pi r h\]
  3. Se reemplaza: \[A=2\cdot\pi\cdot 3\ \text{cm}\cdot 10\ \text{cm}\]
  4. Se multiplican los números: \(2\cdot 3\cdot 10=60\). \[A=60\pi\ \text{cm}^2\]
  5. Con \(\pi\approx 3{,}1416\): \[A\approx 60\cdot 3{,}1416\ \text{cm}^2\approx 188{,}5\ \text{cm}^2\]

BCalcula el área del mismo cilindro, de radio \(3\ \text{cm}\) y altura \(10\ \text{cm}\), ahora con sus dos tapas.

Pista

Usa \(A=2\pi r\,(h+r)\), o suma al resultado anterior las dos tapas.

Solución paso a paso
  1. Fórmula con tapas: \[A=2\pi r\,(h+r)\]
  2. Se reemplaza: \[A=2\cdot\pi\cdot 3\ \text{cm}\cdot(10\ \text{cm}+3\ \text{cm})\]
  3. Se resuelve el paréntesis: \[A=2\cdot\pi\cdot 3\ \text{cm}\cdot 13\ \text{cm}\]
  4. Se multiplican los números: \(2\cdot 3\cdot 13=78\). \[A=78\pi\ \text{cm}^2\approx 245{,}0\ \text{cm}^2\]
  5. Comprobación sumando las partes. El área sin tapas era \(60\pi\ \text{cm}^2\) y cada tapa mide \(\pi\cdot 3^2=9\pi\ \text{cm}^2\): \[60\pi+9\pi+9\pi=78\pi\ \text{cm}^2\]

CUn tarro cilíndrico de lata, abierto por arriba, tiene radio \(4\ \text{cm}\) y altura \(12\ \text{cm}\). ¿Cuánta lata se necesita para fabricarlo? Tiene fondo, pero no tiene tapa superior.

Pista

Cuenta el rectángulo lateral y un solo círculo.

Solución paso a paso
  1. El tarro tiene la superficie lateral y una sola tapa, el fondo: \[A=2\pi r h+\pi r^2\]
  2. Área lateral: \[2\pi r h=2\cdot\pi\cdot 4\ \text{cm}\cdot 12\ \text{cm}=96\pi\ \text{cm}^2\]
  3. Área del fondo: \[\pi r^2=\pi\cdot(4\ \text{cm})^2=16\pi\ \text{cm}^2\]
  4. Suma: \[A=96\pi\ \text{cm}^2+16\pi\ \text{cm}^2=112\pi\ \text{cm}^2\]
  5. Con \(\pi\approx 3{,}1416\): \[A\approx 112\cdot 3{,}1416\ \text{cm}^2\approx 351{,}9\ \text{cm}^2\]
